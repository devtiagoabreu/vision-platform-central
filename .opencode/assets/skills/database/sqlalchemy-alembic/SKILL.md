# SQLAlchemy + Alembic (PostgreSQL)

## Overview

SQLAlchemy 2.0 is the ORM for the Vision Platform Core. The platform uses one
shared PostgreSQL 16 database where every table carries an obligatory tenant
reference. All models are async-first. This skill covers the conventions used
across the platform: declarative models, UUID public ids with integer internal
keys, audit columns, tenant scoping, and the Alembic migration workflow.

## Prerequisites

- PostgreSQL 16 running locally or via Docker
- `sqlalchemy[asyncio]`, `asyncpg`, `alembic`, `pydantic` installed
- Familiarity with Python type hints and asyncio

## Usage Instructions

### Step 1: Base model with shared conventions

Define a base that adds audit columns and a UUID public id:

```python
# app/models/base.py
import uuid
from datetime import datetime
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import DateTime, String, func


class Base(DeclarativeBase):
    pass


class AuditMixin:
    id: Mapped[str] = mapped_column(
        String(36), primary_key=True, default=lambda: str(uuid.uuid4())
    )
    created_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now()
    )
    updated_at: Mapped[datetime] = mapped_column(
        DateTime(timezone=True), server_default=func.now(), onupdate=func.now()
    )
```

### Step 2: Tenant scoping

Every business table references the tenant. Store `tenant_id` and index it:

```python
class TenantOwned:
    tenant_id: Mapped[str] = mapped_column(String(36), index=True)
```

```python
# app/models/camera.py
from sqlalchemy import String
from sqlalchemy.orm import Mapped, mapped_column
from app.models.base import Base, AuditMixin, TenantOwned


class Camera(AuditMixin, TenantOwned, Base):
    __tablename__ = "cameras"

    name: Mapped[str] = mapped_column(String(200))
    source_type: Mapped[str] = mapped_column(String(20))  # rtsp | usb | file
    rtsp_url: Mapped[str | None] = mapped_column(String(500))
    status: Mapped[str] = mapped_column(String(20), default="disconnected")
```

### Step 3: Async session dependency

Provide a per-request async session, scoped to the tenant in service layer:

```python
# app/core/db.py
from sqlalchemy.ext.asyncio import AsyncSession, create_async_engine, async_sessionmaker

engine = create_async_engine("postgresql+asyncpg://user:pass@localhost/vision")
SessionLocal = async_sessionmaker(engine, expire_on_commit=False)


async def get_db_session():
    async with SessionLocal() as session:
        yield session
```

### Step 4: Alembic setup

Initialize Alembic and wire it to the Base metadata:

```bash
alembic init alembic
```

Set `target_metadata = Base.metadata` in `alembic/env.py` and update
`sqlalchemy.url` (or use env vars). Then:

```bash
alembic revision --autogenerate -m "add cameras table"
alembic upgrade head
```

### Step 5: Migration hygiene

- Review every autogenerated migration before applying it.
- Never store secrets in migrations or models.
- Adding a `NOT NULL` column to a populated table needs a two-step migration
  (add nullable, backfill, then set NOT NULL).

## Examples

### Example 1: Query scoped by tenant

```python
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession


async def list_cameras(session: AsyncSession, tenant_id: str):
    stmt = select(Camera).where(Camera.tenant_id == tenant_id).order_by(Camera.created_at)
    result = await session.execute(stmt)
    return result.scalars().all()
```

### Example 2: One-to-many tenant-owned relationship

```python
from sqlalchemy.orm import relationship


class Plugin(AuditMixin, TenantOwned, Base):
    __tablename__ = "plugins"
    name: Mapped[str] = mapped_column(String(200))
    module_key: Mapped[str] = mapped_column(String(100), index=True)
    enabled: Mapped[bool] = mapped_column(default=True)
    executions = relationship("Execution", back_populates="plugin")


class Execution(AuditMixin, TenantOwned, Base):
    __tablename__ = "executions"
    plugin_id: Mapped[str] = mapped_column(String(36))
    status: Mapped[str] = mapped_column(String(20))
    plugin = relationship("Plugin", back_populates="executions")
```

## Notes

- One shared PostgreSQL database; every table requires a tenant reference.
- Public ids are UUID strings; keep small integer internal keys for hot paths.
- `created_at`/`updated_at` come from the `AuditMixin` — always include them.
- Modules must not create their own tables; module data lives in JSON columns
  on generic platform entities (VP-008).
- Run `alembic upgrade head` in deploy pipelines, and test downgrades locally.
